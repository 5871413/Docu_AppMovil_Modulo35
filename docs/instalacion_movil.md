# Guía de Instalación y Configuración del Entorno Móvil

## 1. Requisitos

- Android 8.0 o superior.
- Mínimo 100 MB de almacenamiento disponible.
- Conexión a Internet o Wi-Fi.
- Archivo APK de la aplicación.

## 2. Instalación

1. Descargar el archivo APK.
2. Abrir el archivo APK.
3. Permitir la instalación cuando el dispositivo lo solicite.
4. Instalar la aplicación.
5. Abrir la aplicación.
6. Iniciar sesión.
7. Comprobar la conexión con el servidor.

## 3. Prueba

Después de iniciar sesión correctamente, la aplicación debe mostrar la pantalla principal correspondiente al tipo de usuario.

El cliente podrá gestionar sus pedidos.

El repartidor podrá consultar y actualizar sus entregas.
