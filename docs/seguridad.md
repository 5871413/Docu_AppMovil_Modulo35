# Políticas de Seguridad de la Aplicación Móvil

## 1. Almacenamiento Local Seguro

Los tokens de sesión no deben guardarse en texto plano.

Se recomienda utilizar almacenamiento seguro del dispositivo.

## 2. Permisos

La aplicación solamente debe solicitar los permisos necesarios para su funcionamiento.

## 3. Autenticación

El acceso debe realizarse mediante usuario y contraseña.

Las solicitudes deben utilizar conexiones seguras.

## 4. Protección de Datos

La aplicación debe evitar almacenar información sensible innecesaria.

## 5. Control de Acceso

Solamente los usuarios autorizados pueden modificar información de pedidos.

## 6. Repartidor


El repartidor solamente debe poder modificar los pedidos que tenga asignados.
